# Mobile header regression checklist

- 720px: brand, Search, and Menu fit without overlap.
- 390px: Search remains visible and Menu remains operable.
- 350px: compact controls remain available; wordmark may collapse below this width.
- Open menu stays inside the viewport and scrolls internally when content exceeds available height.
- Search/Menu remain keyboard-focusable and use the global visible-focus treatment.
- No desktop navigation rules are changed by this mobile-only stylesheet.
