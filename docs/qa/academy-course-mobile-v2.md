# Academy course mobile QA

This bounded pass protects course-detail responsiveness without changing course data or desktop mechanics.

- Long course titles wrap safely on narrow screens.
- Panels and learning outcomes use reduced mobile padding.
- Unit rows retain clear touch interaction and state feedback.
- Exercise/resource links have mobile-sized targets.
- Course footer actions stack to one column on phones.
- Narrow-phone rules remain scoped below 380px.
