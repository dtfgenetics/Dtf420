# Mobile homepage contract

The homepage mobile layer should keep the primary experience concise without changing desktop structure:

- Hero typography stays below the oversized desktop scale.
- Primary hero actions stack only on narrow phones.
- Discovery remains a compact two-column grid in the normal phone range.
- Feature and action cards remove desktop minimum heights on mobile.
- Header Search and Menu remain reachable on narrow phones.

See `app/home-mobile.css` for the bounded overrides.
