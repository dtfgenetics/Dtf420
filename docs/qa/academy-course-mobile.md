# Mobile Academy course regression checklist

- 620px and below: course title and summary remain readable without horizontal overflow.
- Course outcomes and panels use compact mobile padding without clipping list markers.
- Unit rows remain full-row links with touch-friendly spacing and visible Open feedback.
- Applied exercise and capstone resource links provide at least 46px mobile targets.
- Footer actions stack to one column and provide at least 48px targets.
- 380px and below: long titles wrap safely and panel padding remains usable.
- Desktop two-column course layout remains unchanged above the responsive breakpoints.
