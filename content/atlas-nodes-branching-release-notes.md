# Nodes & Branching expansion — 2026-09-02

This expansion grows the canonical Nodes & Branching system from six to ten lessons while preserving the existing route order and adding source-backed coverage for axillary-bud activation, multi-signal branching physiology, Cannabis phyllotaxy/developmental nodes, and pruning-driven architectural plasticity.

## Evidence boundaries

- Cannabis-specific morphology and pruning claims are tied to Cannabis sativa studies.
- Auxin, cytokinin, strigolactone, sugar, and light signaling are described as broader flowering-plant mechanisms unless Cannabis-specific evidence is available.
- Branch-junction finite-element evidence is used only as a conceptual biomechanics reference and is not presented as measured Cannabis strength data.
- Study-specific pruning and yield outcomes are not converted into universal grower formulas.

## New visual production targets

1. Dormant-to-active axillary bud developmental sequence.
2. Node-centered auxin/cytokinin/strigolactone/sugar/light interaction map.
3. Cannabis node and phyllotaxy developmental reference strip.
4. Cannabis pruning-treatment architecture and response matrix.
